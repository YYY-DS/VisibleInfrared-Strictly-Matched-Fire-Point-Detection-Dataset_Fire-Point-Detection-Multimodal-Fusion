## 数据三要素解析

**类别与目标覆盖**
*   数据集定义 **1** 个核心类别：**火点**（fire），聚焦单一目标，便于快速部署与高精度检测。
*   火点在红外图像中呈现为高温亮区，在可见光中可能呈现为火焰或烟雾形态，两者互补性强。
*   可见光与红外严格配对，为多模态融合检测提供了理想的数据基础。

**数据规模与配对**
*   图像总量约 **1367** 张，其中 **1298** 张包含火点标注，其余为负样本或无标注图像。
*   数据全部用于训练（训练集1367张），无预定义验证/测试集划分，用户可自行划分。
*   可见光与红外图像**严格配对**（同一时间、同一位置、同一角度），确保了模态间的空间一致性。
*   图像分辨率统一为 **640**，可直接输入常见检测网络。

**格式与结构**
*   同时提供 **YOLO**、**VOC**、**COCO** 三种通用标注格式，灵活适配不同检测框架。
*   图像与标签一一对应，数据结构规范，便于进行预处理与训练流程集成。

## 知识普及：可见光-红外配对火点检测的技术要点

*   **多模态互补性**：可见光图像提供火焰形态、烟雾纹理等视觉信息；红外图像提供温度分布信息，不受光照影响。两者结合可提升火点检测的可靠性，尤其在夜间或烟雾遮挡场景。
*   **严格配对价值**：严格配对（同一时间、位置、角度）的图像可用于像素级或特征级融合研究，提升多模态检测精度。
*   **火点识别特征**：红外图像中火点呈高温亮斑，可见光中可能呈现火焰（橙红色）或烟雾（灰白色）。模型需学习两种模态下的火点特征。
*   **早期火灾检测**：火灾初期可能仅有烟雾或微小热源，需模型具备较高的敏感度。
*   **多模态融合策略**：
    *   **早期融合**：将可见光与红外图像在输入层拼接。
    *   **中期融合**：分别提取两种模态特征，在网络中间层融合。
    *   **晚期融合**：分别检测后，对结果进行决策级融合。
*   **应用闭环**：检测结果可结合GPS信息，生成火点分布图，辅助消防指挥与应急响应。

## 快速开始（代码示例）

配置文件 `data.yaml` 示例：
```yaml
train: ./dataset/images/train
val: ./dataset/images/val
nc: 1
names: ['fire']
```

启动 YOLOv8 训练：
```python
from ultralytics import YOLO

model = YOLO('yolov8m.pt')
model.train(
    data='data.yaml',
    epochs=100,
    imgsz=640,
    batch=16,
    device=0
)
```
